## `filter`

`filter`は`true`になった要素のみを返すものらしい．使いこなせたらかなり便利そう．

```js
let a = [];
for (let i = 0; i < 10; ++i)
{
    a.push(i);
}

const b = a.filter(x => {
    return x & 1;
});

console.log(b);
```

```sh
# 出力結果
> [ 1, 3, 5, 7, 9 ]
```

## `map`

`map`は各要素に対してコールバック函数なるものを実行するらしい．

```js
let a = [];
let even = [];
let odd = [];
for (let i = 0; i < 10; ++i)
{
    a.push(i);
}

a.map(x => {
    if (x & 1)
    {
        odd.push(x);
    }
    else
    {
        even.push(x);
    }
});

console.log(odd);
console.log(even);
```

```sh
# 出力結果
> [ 1, 3, 5, 7, 9 ]
[ 0, 2, 4, 6, 8 ]
```

`return`して，各要素に何らかの操作をした配列を返すこともできる．

```js
let a = [];
for (let i = 0; i < 10; ++i)
{
    a.push(i);
}

const b = a.map(x => {
    return Math.sqrt(x)
});

console.log(b);
```

```sh
# 出力結果

  1,
  1.4142135623730951,

  2.8284271247461903,
  3
]
```

## `reduce`

`reduce`もコールバック函数を呼び出すが`map`とは少し違う．`reduce`に入るコールバック函数は，第一引数が**直前のコールバック函数の戻り値**，または**初期値**で，第二引数が**現在の要素**である．
従って，配列の総和とか総積とか，なんかそう言ったことに向いてそうである．

```js
let a = [];
for (let i = 0; i < 10; ++i)
{
    a.push(i + 1);
}

const b = a.map(x => {
    return Math.log(x);
});

const val = b.reduce((acc, cur) => {
    return acc + cur;
}, 0);

console.log(val);
console.log(Math.pow(Math.E, val))
```

```sh
# 出力結果
> 15.104412573075518
3628800.0000000056
```
