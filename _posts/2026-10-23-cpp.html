std::function

std::functionはcallableなオブジェクトを柔軟に格納してくれる便利な奴らしい．functionalをincludeする必要がある．

{% highlight cpp %} #include #include #include int main() { std::function zeta = [](double x, int n) { double sum = 0; for (int i = 1; i <= n; ++i) { sum += 1.0 / pow(static_cast(i), x); } return sum; }; printf("%f\n", zeta(2, 100)); return 0; } {% endhighlight %}
{% highlight sh %} # 出力結果 > 1.634984 {% endhighlight %}

更に，[&]とすると，スコープ内の変数を参照できる．

{% highlight cpp %} #include #include #include int main() { double sum = 0; std::function zeta = [&](double x, int n) { sum = 0; for (int i = 1; i <= n; ++i) { sum += 1.0 / pow(static_cast(i), x); } return sum; }; printf("%f\n", zeta(2, 100)); return 0; } {% endhighlight %}

この前，ブロック行列を作るときにちょっと利用したが，今後使う機会は恐らくおぼないだろう．
