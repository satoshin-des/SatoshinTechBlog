# ``std::function``

``std::function``はcallableなオブジェクトを柔軟に格納してくれる便利な奴らしい．``functional``をincludeする必要がある．

```cpp
#include <iostream>
#include <cmath>
#include <functional>

int main()
{
    std::function<double(double, int)> zeta = [](double x, int n)
    {
        double sum = 0;
        for (int i = 1; i <= n; ++i)
        {
            sum += 1.0 / pow(static_cast<double>(i), x);
        }
        return sum;
    };
    
    printf("%f\n", zeta(2, 100));
    
    return 0;
}
```

```sh
> 1.634984
```

更に，``[&]``とすると，スコープ内の変数を参照できる．

```cpp
#include <iostream>
#include <cmath>
#include <functional>

int main()
{
    double sum = 0;
    
    std::function<double(double, int)> zeta = [&](double x, int n)
    {
        sum = 0;
        for (int i = 1; i <= n; ++i)
        {
            sum += 1.0 / pow(static_cast<double>(i), x);
        }
        return sum;
    };
    
    printf("%f\n", zeta(2, 100));
    
    return 0;
}
```
