# `fplll::lll_reduction`

基底行列にLLL簡約を施すという点では，例えばNTLライブラリの`NTL::LLL_FP`なんかと同じだが，NTLのものよりはるかに使い勝手が良い．具体的には，NTLのよりパラメタの設定が良い感じ．

```fplll
#include <iostream>
#include <fplll.h>

int main()
{
    fplll::ZZ_mat<mpz_t> B(10, 10);

    for (int i = 0; i < 10; ++i)
    {
        mpz_set_str(B[i][i].get_data(), "1", 10);
        mpz_set_str(B[i][0].get_data(), std::to_string(rand()).c_str(), 10);
    }

    std::cout << B << std::endl;
    fplll::lll_reduction(B, 0.99, 0.51, fplll::LM_WRAPPER, fplll::FT_DEFAULT, 0, fplll::LLL_VERBOSE);
    std::cout << B << std::endl;

    return 0;
}
```

`lll_reduction`の各引数と，そこに入る値は次のようになっている．

|引数|名前|概要|指定可能なもの|
|:-|:-|:-|:-|:-|
|第一引数|`b`|基底行列|行列|
|第二引数|`delta`|Lovász条件のパラメタ|0.25 ～ 1|
|第三引数|`eta`|サイズ簡約条件のパラメタ|0 ～ √delta|
|第四引数|`method`|精度と速度の制御|`LM_FAST`, `LM_HEURISTIC`, `LM_PRPVED`, `LM_WRAPPER`|
|第五引数|`floatType`|浮動小数点のタイプ|`FT_DD`, `FT_DEFAULT`, `FT_DOUBLE`, `FT_DPE`, `FT_LONG_DOUBLE`, `FT_MPFR`, `FP_QD`|
|第六引数|`precision`|MPFR精度を選んだときのbit精度|0以上|
|第七引数|`flag`|その他細かい設定||

(参考：[fplll Modules — fpylll 0.6.4 documentation](https://fpylll.readthedocs.io/en/latest/modules.html))
