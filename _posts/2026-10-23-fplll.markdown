## 導入方法

```bash
sudo apt-get install libfplll-dev
```

ちなみに実行する際は`-lfplll -lmpfr -lgmp`を指定しなければならないらしい

```bash
g++ hoge.cpp -lfplll -lmpfr -lgmp
```

## `fplll::lll_reduction`

基底行列にLLL簡約を施すという点では，例えばNTLライブラリの`NTL::LLL_FP`なんかと同じだが，NTLのものよりはるかに使い勝手が良い．具体的には，NTLのよりパラメタの設定が良い感じ．

```fplll
#include <iostream>
#include <fplll.h>

int main()
{
    fplll::ZZ_mat<mpz_t> B(10, 10);

    for (int i = 0; i < 10; ++i)
    {
        mpz_set_str(B[i][i].get_data(), "1", 10);
        mpz_set_str(B[i][0].get_data(), std::to_string(rand()).c_str(), 10);
    }

    std::cout << B << std::endl;
    fplll::lll_reduction(B, 0.99, 0.51, fplll::LM_WRAPPER, fplll::FT_DEFAULT, 0, fplll::LLL_VERBOSE);
    std::cout << B << std::endl;

    return 0;
}
```

## `fplll::bkz_reduction`

`fplll::BKZParam`型のオブジェクトを作り，BKZ簡約のパラメタを設定して簡約を行う．

```fplll
#include <iostream>
#include <fplll.h>

int main()
{
    std::vector<fplll::Strategy> strategies = fplll::load_strategies_json("path/to/default.json");
    fplll::ZZ_mat<mpz_t> B(10, 10);
    fplll::BKZParam params(10, strategies, 0.99, fplll::BKZ_VERBOSE | fplll::BKZ_AUTO_ABORT | fplll::BKZ_MAX_LOOPS, 10);

    for (int i = 0; i < 10; ++i)
    {
        mpz_set_str(B[i][i].get_data(), "1", 10);
        mpz_set_str(B[i][0].get_data(), std::to_string(rand()).c_str(), 10);
    }

    std::cout << B << std::endl;
    fplll::bkz_reduction(&B_fplll, NULL, params, fplll::FT_LONG_DOUBLE);
    std::cout << B << std::endl;

    return 0;
}
```
