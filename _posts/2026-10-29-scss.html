インストール方法

gemから簡単にインストールできる．

{% highlight sh %} $ gem install sass-embedded {% endhighlight %}

SCSSからCSSにコンパイルする場合は例えば以下のようにできる．

{% highlight sh %} $ sass scss/style.scss css/style.css {% endhighlight %}

CSSとの相違点

CSSでは

{% highlight scss %} div p { background-color: black; } div > h1 { background-color: red; } div ~ h2 { background-color: blue; } div + h3 { background-color: green; } div:hover { background-color: white; } div::after { content: ';'; } {% endhighlight %}

と書くものは，それぞれ

{% highlight scss %} div { p { background-color: black; } ~h2 { background-color: blue; } +h3 { background-color: green; } &:hover { background-color: white; } &::after { content: ';'; } } {% endhighlight %}

と書ける．

また，次のような構造を仮定する．

{% highlight plaintext %} scss ┣━ layout ┃　　┣━ _header.scss ┃　　┗━ _footer.scss ┗━ style.scss {% endhighlight %}

この場合は，style.scssに

{% highlight scss %} @use 'layout/header'; @use 'layout/footer'; {% endhighlight %}

と書くことで，_header.scssの内容と_footer.scssの内容をstyle.scssへ押し付けられる． これをコンパイルすることで，cssを作ることができる．
