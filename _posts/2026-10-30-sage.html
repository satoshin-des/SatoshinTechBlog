latex

latex函数を利用することで，TeXの形式で数式を出力することができる．

{% highlight sage %} var("x") f = (x - 1) * (x - 2) * pi f = expand(f) print(latex(f)) {% endhighlight %}
{% highlight sh %} # 出力結果 > 2 \, \pi + \pi x^{2} - 3 \, \pi x {% endhighlight %}

更に，ascii_art函数を利用すれば，アスキーアート風に出力をしてくれる．

{% highlight sage %} var("x") f = (x - 1) * (x - 2) * pi f = expand(f) print(ascii_art(f)) {% endhighlight %}
{% highlight sh %} # 出力結果 > 2 pi*x - 3*pi*x + 2*pi {% endhighlight %}
