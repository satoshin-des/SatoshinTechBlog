latex

latex函数を利用することで，TeXの形式で数式を出力することができる．

{% highlight sage %} var("x") f = (x - 1) * (x - 2) * pi f = expand(f) print(latex(f)) {% endhighlight %}
{% highlight sh %} # 出力結果 > 2 \, \pi + \pi x^{2} - 3 \, \pi x {% endhighlight %}

show函数のなかに入れることで，例えばSageMath Cellなどでは綺麗な数式として表示できる．

{% highlight sage %} var("x") f = (x - 1) * (x - 2) * pi f = expand(f) show(latex(f)) {% endhighlight %}

更に，ascii_art函数を利用すれば，アスキーアート風に出力をしてくれる．

{% highlight sage %} var("x") f = (x - 1) * (x - 2) * pi f = expand(f) print(ascii_art(f)) {% endhighlight %}
{% highlight sh %} # 出力結果 > 2 pi*x - 3*pi*x + 2*pi {% endhighlight %}

groebner_basis

groebner_basis函数を利用することで，簡単にGroebner基底を求めることができる．

{% highlight sage %} R. = PolynomialRing(QQ, order='lex') I = Ideal(x1+x2+x3, x1^3+x2^3+x3^3) gb = I.groebner_basis() print(gb) {% endhighlight %}
{% highlight sh %} # 出力結果 > [x1 + x2 + x3, x2^2*x3 + x2*x3^2] {% endhighlight %}
