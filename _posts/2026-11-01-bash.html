tee

標準出力されたものをすべてファイルに書きこむ．

{% highlight bash %} $ echo "hello, world" | tee file.txt hello, world $ cat file.txt hello, world {% endhighlight %}

しかし，エラーが発生した場合はファイルに何も書き込むことができなくなってしまう．

{% highlight bash %} $ ./does-not_exist.out | tee file.txt -bash: ./does-not_exist.out: No such file or directory $ cat file.txt {% endhighlight %}

この場合は2>&1をつけることで解決する．

{% highlight bash %} $ ./does-not_exist.out 2>&1 | tee file.txt -bash: ./does-not_exist.out: No such file or directory ~$ cat file.txt -bash: ./does-not_exist.out: No such file or directory {% endhighlight %}
