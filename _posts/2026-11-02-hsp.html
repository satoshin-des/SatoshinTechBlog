HSPの中でJscriptを動かす

HSPの中でJscriptを動かすには，newcomでCOMオブジェクトを作る必要がある．

{% highlight hsp %} newcom sc, "MSScriptControl.ScriptControl" sc("Language") = "JScript" {% endhighlight %}

応用：文字列を数式として解釈し，グラフを描く

まずはソースを載せる．

{% highlight hsp %} #const WINX 640 #const WINY 480 screen 0, WINX, WINY newcom sc, "MSScriptControl.ScriptControl" sc("Language") = "JScript" ; 原点と倍率 cx = WINX / 2.0 cy = WINY / 2.0 scale = 40.0 ; x軸とy軸を描画 color 255, 255, 255 : cls color 180, 180, 180 line 0, cy, WINX, cy line cx, 0, cx, WINY ; 数式を表す文字列 expr = "Math.sin(x) * 2 + Math.cos(x * 3)" ; JScriptからの戻り値を受け取るための変数 comres res color 255, 0, 0 first = 1 repeat WINX ; 数学座標に変換 x = double(cnt - cx) / scale ; JScriptで変数xへ代入 sc->"ExecuteStatement" "var x = " + strf("%f", x) + ";" ; 数式をJScript側で評価してyへ代入 sc->"Eval" expr y = double(res) ; 画面座標に変換 py = cy - y * scale ; 画面範囲内では線を描画 if 0 =< py & py <= winy { if first { pos cnt, py first = 0 } else { line cnt, py } } else { first = 1 } loop stop {% endhighlight %}

comres resとすることにより，JScriptからの結果を受け取るための変数を用意している． これがないといくら計算しても結果が受け取れない．
sc->"ExecuteStatement" "var x = " + strf("%f", x) + ";"とすることで，「var x = [値];」をJScriptとして実行する． これにより，変数xが設置される．
sc->"Eval" exprとすることで，ExecuteStatementで定義されたxを参照し，exprを評価してresへ入れている． これを浮動小数点数としてyにいれる．
また，HSPでは

{% highlight hsp %} pos x1, y1 line x2, y2 {% endhighlight %}

で(x1, y1)から(x2, y2)へ直線が引けるため，これを利用して曲線っぽく線を描画する．

実際に上のコードで実行すると次のようなものが出力される．

FPSを表示する

自分で函数かなんかを作るのも良いが，d3getfpsを使うのが簡単

{% highlight hsp %} #include "d3m.hsp" *main redraw 0 color 255, 255, 255: boxf pos 0, 0 color 0, 0, 0 mes strf("%dFPS", d3getfps()) redraw 1 await 16 goto *main {% endhighlight %}

これを実行すると，多少の誤差はあろうが概ね次のようになる．
