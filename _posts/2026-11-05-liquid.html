contains

containsを利用することで，例えば文字列のなかに特定の文字列が含まれているかを簡単に判定することができる．
{% highlight json %} { "name": "liquid", "humen": [ "Taro Sato", "Miyuki Yamada", "Madoka Sato", "Takuya MIzoguchi" ] } {% endhighlight %}
{% highlight liquid %} {% raw %} {% for h in humen %} {% if h contains "Sato" %}

{{h}}

{% endif %} {% endfor %} {% endraw %} {% endhighlight %}
{% highlight bash %} # 実行結果 Output

Taro Sato

Madoka Sato

{% endhighlight %}
