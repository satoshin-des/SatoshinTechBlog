Windowsでの方法

まず，いくつかインストールするものがあるので，それをインストールする．

{% highlight powershell %} winget install neovim winget install sharkdp.fd winget install BurntSushi.ripgrep.MSVC {% endhighlight %}

その後は，Neiovimのバックアップをしておきます． この際にファイルが存在しない的なエラーを吐く場合があるが，その場合はバックアップするファイルが存在しないということなので，無視で良い．

{% highlight powershell %} Move-Item $env:LOCALAPPDATA\nvim $env:LOCALAPPDATA\nvim.bak Move-Item $env:LOCALAPPDATA\nvim-data $env:LOCALAPPDATA\nvim-data.bak {% endhighlight %}

この後にすぐにnvimで起動しようとしたら，私の環境ではnvimが認識されなかったので，一度powershellを再起動すると良い．
nvimを実行すれば勝手に色々とインストールが進み，インストールが完了する．
